## 2026-05-21 ~14:07 AEST — M25A Hardcoded Phrase Regression + Permanent Hard Rule

### Regression Failure Documented
Stick identified that the M25A visibleTextClassifier was hardcoding phrases as routing
triggers:
- `"Run it."` caught by `lower.startsWith('run ')` → misclassified as `tool_action`
- `"Proceed."` caught by single-word fallback → misclassified as `short_ambiguous_no_context`
  (with valid context present)

Root cause: the classifier used fixed phrase matching (startsWith, exact string arrays)
before scoring ambiguous signals with context. This is the exact anti-pattern the M25A
spec prohibits.

### Hard Rule (Permanent)

**Words are evidence, not routing rules.**

No route may emerge from a single word or phrase. A route must emerge from a scored
contract: prompt shape + context gate + active obligation + risk + confidence threshold.

- No `if prompt contains X then route Y` outside of a tiny explicit deny/allow safety list.
- Short ambiguous phrases ("continue", "do it", "run it", "fix it", "go ahead") must be
  scored using multi-feature evidence, not phrase matching.
- If confidence is below threshold → safe clarification or simple chat, never speculative
  execution.
- This rule applies to all preselectors, classifiers, intent scorers, and routing
  decisions across all OpenClaw vMesh services.
