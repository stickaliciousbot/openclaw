# Apps

Application workspace for future tools that support customer and opportunity tracking.

## Suggested application areas

| Area | Purpose |
|---|---|
| `opportunity-tracker/` | Future app surface for markdown-backed opportunity records. |
| `customer-briefing-generator/` | Future tooling to generate customer profiles, briefing notes, and call plans. |
| `dashboard/` | Future reporting or visualisation layer. |

Keep app folders lightweight until implementation starts. Link application records back to markdown source-of-truth files in `customers/` and `opportunities/`.
