# Opportunities

Markdown-first opportunity tracker organized by customer and pipeline status.

## Pipeline folders

| Folder | Use |
|---|---|
| `new/` | New lead or opportunity, not yet qualified. |
| `in-progress/` | Active sales, discovery, demo, proposal, or implementation motion. |
| `stale/` | Needs revive, archive, or close decision. |
| `won/` | Closed won or strategically secured. |
| `lost/` | Closed lost or explicitly rejected. |
| `inactive/` | Parked opportunity not currently being pursued. |

## Opportunity record pattern

Each opportunity file should include YAML front matter followed by markdown sections:

1. Snapshot
2. Customer context
3. Contacts
4. Business problem / hypothesis
5. Current status
6. Next action
7. Activity log
8. Notes / risks
