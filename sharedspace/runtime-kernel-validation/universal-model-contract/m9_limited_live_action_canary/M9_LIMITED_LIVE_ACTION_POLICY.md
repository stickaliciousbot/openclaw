# M9 Limited Live-Action Policy

Status: `PASS_M9_LIMITED_LIVE_ACTION_POLICY_DEFINED`

M9 permits preparation only until exact operator approval. One explicitly approved, low-risk, receipt-backed canary action may run later. It must have VerifiedRoute, capability manifest eligibility, M7 model/fallback eligibility, ContractEnvelope, DeliveryReceipt, TerminalContractCloseout, explicit postconditions, and rollback/cleanup.

M9 does not grant broad production authority and does not authorize M10 production enforcement.
