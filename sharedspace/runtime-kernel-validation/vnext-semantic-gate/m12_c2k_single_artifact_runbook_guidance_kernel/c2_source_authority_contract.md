# C2 Source Authority Contract

- Authority is one approved immutable artifact only.
- Source refs must appear in structured `cited_source_refs` and step-level `source_ref_ids`; prose/disposition-only refs are rejected.
- Section ids must match compiled deterministic sections from the same artifact.
- Memory, context-bridge, daily-memory, arbitrary paths, cross-artifact comparison, and multi-source drafting reject/HOLD.
- Model/prose text cannot satisfy source authority.
